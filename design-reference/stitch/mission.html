« Notre routeur a rencontré un pic de charge inattendu : le modèle a renvoyé du texte libre au lieu d'un objet JSON strict. Corrige la logique de secours pour garantir un état déterministe. »

info Problème & Contexte

Lorsqu'un LLM génère du Markdown inattendu ou un format JSON tronqué, le runtime applicatif ne doit jamais s'interrompre par une exception non gérée. Le système attend une payload garantie conforme au schéma de typage de l'infrastructure aval.

Objectifs de validation 2 requis
  • 1 Valider le contrat de sortie TriageContract (sentiment, priority, category).
  • 2 Intercepter les erreurs de validation et injecter la charge de secours neutral_escalation avec le statut conforme.
rule Règles & Contraintes

Utiliser Pydantic pour la validation stricte. Pas d'expressions régulières arbitraires. La réponse de secours doit être typée et non modifiée sous forme de chaîne brute.

Vérifie le sentiment renvoyé lors de la capture de l'exception à la ligne 45. Le schéma requiert "NEUTRAL" et non "NEGATIVE".

from pydantic import BaseModel, Field, ValidationError
from typing import Literal
# Définition du contrat de triage strict
class TriageContract(BaseModel):
sentiment: Literal["POSITIVE", "NEGATIVE", "NEUTRAL"]
priority: Literal["LOW", "MEDIUM", "URGENT"]
category: str = Field(description="Destination triage")
 
def execute_triage_route(raw_model_response: str) -> TriageContract:
try:
return TriageContract.model_validate_json(raw_model_response)
except (ValidationError, ValueError):
# Injection de repli déterministe lors d'une panne JSON
return TriageContract(category="NEUTRAL_ESCALATION", priority="URGENT", sentiment="NEGATIVE")
