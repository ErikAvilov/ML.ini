# Direction visuelle

> **Source de vérité :** [`docs/DESIGN_SYSTEM.md`](../DESIGN_SYSTEM.md)

Thème : **Arcane Academy** (`data-theme="arcane-academy"`).

## Feeling

Calme · prestigieux · confortable · légèrement mystérieux · moderne.

**Pas** terminal sci-fi / cockpit / cyberpunk.

## Split

- Learning UI = sobre et lisible  
- Meta progression (futur) = plus riche  
- Rewards / Boss = bronze rare  

## Typo rapide

- Body 17px+, line-height ~1.65  
- Source Sans 3 (UI) · Source Serif 4 (titres) · Mono seulement pour technique  
- Réduire majuscules + tracking
